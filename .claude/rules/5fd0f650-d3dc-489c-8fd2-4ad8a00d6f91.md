### Rules

- **R-CACHE-001** MUST: Implement cache layer pattern for browser runtime and cookie management APIs to store and reuse frequently accessed data, browser instances, and CDP session information.
- **R-CACHE-002** MUST: Implement caching at the data layer for public/external APIs, ensuring that expensive browser operations, configuration lookups, and CDP communications are cached and reused rather than repeatedly executed.
- **R-CACHE-003** MUST: Integrate cache layer into the runtime index, browser configuration, CDP client, and Chromium implementation modules to provide consistent caching behavior across the API surface.
- **R-CACHE-004** MUST: Implement cache invalidation logic to ensure stale data does not cause issues and to prevent cache-related bugs.
- **R-CACHE-005** MUST: Implement careful cache lifecycle management to prevent memory leaks from long-lived browser instances and cached session data.
- **R-CACHE-006** SHOULD: Cache browser sessions and configurations to minimize unnecessary browser launches and reduce load on browser automation infrastructure.
- **R-CACHE-007** SHOULD: Optimize cache strategy to balance performance improvements (reduced redundant operations, faster API response times) against increased memory footprint.
- **R-CACHE-008** MAY: Monitor and measure cache hit rates, performance improvements, and resource consumption to validate effectiveness of caching strategy.

### Verify

```bash
# Verify cache implementation exists in browser and cookies packages
find packages/browser packages/cookies -type f -name "*cache*" -o -name "*Cache*" 2>/dev/null | head -20

# Check for cache integration in runtime index, browser configuration, CDP client, and Chromium implementation
grep -r "cache" packages/browser/src/runtime/index.* packages/browser/src/config.* packages/browser/src/cdp/client.* packages/browser/src/chromium.* 2>/dev/null | head -20

# Verify cache invalidation logic exists
grep -r "invalidate\|clear.*cache\|cache.*clear\|evict" packages/browser packages/cookies 2>/dev/null | head -10

# Check for cache lifecycle management (cleanup, disposal, memory management)
grep -r "dispose\|cleanup\|destroy.*cache\|cache.*destroy" packages/browser packages/cookies 2>/dev/null | head -10
```

**Accept when:**
- Cache layer is implemented in browser runtime and cookie management modules
- Caching is integrated into runtime index, browser configuration, CDP client, and Chromium implementation
- Cache invalidation logic is present and handles stale data
- Cache lifecycle management prevents memory leaks from cached browser instances
- Consistent caching strategy is applied across both browser and cookies packages
- Performance improvements are achieved through reduced redundant browser operations and CDP calls

<enforcement>
Claude Code MUST verify cache implementation, invalidation logic, and lifecycle management before accepting changes to browser runtime and cookie management APIs. Verification MUST NOT be skipped or deferred.
</enforcement>
